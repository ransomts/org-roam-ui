#+title: Heading Anchors Demo

This note demonstrates clickable heading anchor links in the
org-roam-ui preview pane. Hover over any heading to see a =#= link
appear. Click it to navigate directly to that section.

* Introduction

This is the first section. Try hovering over the heading above —
you should see a small =#= appear to its right.

* Getting Started

Anchor links make it easy to reference specific sections in long notes.

** Prerequisites

Nested headings also get anchor links at every level.

** Installation

Each heading's anchor uses the slug generated by =uniorg-slug=.

*** From Source

Even deeply nested headings (h3 and beyond) have anchors.

* API Reference

** Authentication

The anchor link uses the heading's =id= attribute for the URL fragment.

** Endpoints

*** GET /users

Clicking the anchor scrolls the preview pane to that heading.

*** POST /users

Useful for navigating long reference documents.

* Conclusion

Every heading level from h1 through h6 supports anchor links.
